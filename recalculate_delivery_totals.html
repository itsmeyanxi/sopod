🔧 Recalculate Delivery Totals

This tool fixes incorrect total amounts caused by decimal truncation issues.

⚠️ Warning: This operation will update delivery item totals in the database. Only Admin and IT users can run this.
What this does:
  • Recalculates total_amount for each delivery item
  • Uses formula: quantity × unit_price
  • Only updates items where the total is incorrect
  • Logs all changes to the activity log
